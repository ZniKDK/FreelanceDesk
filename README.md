# FreelanceDesk

Десктоп-приложение для самозанятого фрилансера: заказы, клиенты, сроки, оплаты, доход и налог НПД. Работает сразу после запуска, сервер базы данных не нужен.

![Заказы](docs/screenshot.png)

## Возможности

**Заказы**
- Сумма, дедлайн, статус (новый → в работе → сдан → оплачен / отменён), дата оплаты, описание и ссылка на заказ.
- Выборки: активные, просроченные, «сдать сегодня», оплаченные без чека; поиск по названию, описанию и клиенту.
- Подсветка: просроченные — красным, срок сегодня — оранжевым, оплата без чека — жёлтым.
- Правая кнопка мыши по заказу: смена статуса, отметка «чек выбит», переход по ссылке.
- Сортировка по любой колонке; по умолчанию срочные заказы сверху.

**Плашка «Требует внимания»** над вкладками: сколько заказов просрочено, сколько сдать сегодня и по скольким оплатам не выбит чек в «Мой налог». Щелчок по цифре открывает эти заказы.

**Клиенты** — тип (физлицо или юрлицо/ИП), контакт, площадка, число заказов и оплаченная сумма.

**Сводка**
- Цель на месяц и прогресс.
- Налог за прошлый месяц и срок уплаты (до 28-го числа).
- Доход, налог и доход после налога за любой период, разбивка по площадкам.
- Диаграмма дохода за последние 12 месяцев.

Налог считается по ставкам НПД: 4 % с оплат от физлиц, 6 % — от юрлиц и ИП.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+N / Ctrl+Shift+N | новый заказ / новый клиент |
| F2 или Enter | изменить выбранное |
| Delete | удалить выбранное |
| Ctrl+F | поиск по заказам |
| Ctrl+R | отметить «чек выбит» |
| F5 | обновить |

## Установка и запуск

Нужен Python 3.11 или новее.

```powershell
git clone https://github.com/ZniKDK/FreelanceDesk.git
cd FreelanceDesk
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

При первом запуске программа создаёт папку `%APPDATA%\FreelanceDesk`:

| Файл | Что в нём |
|---|---|
| `config.ini` | где хранить данные |
| `freelancedesk.db` | база SQLite с заказами и клиентами |
| `ui_state.ini` | размер окна, фильтр, цель на месяц |

Папку можно открыть из меню **Файл → Открыть папку с данными**. Чтобы хранить данные в другом месте (например, на флешке), задайте переменную окружения `FREELANCEDESK_HOME`.

### PostgreSQL (необязательно)

SQLite хватает для одного пользователя. Если нужен сервер PostgreSQL (14+):

1. Создайте пользователя и базу:
   ```sql
   CREATE ROLE freelancedesk LOGIN PASSWORD 'ваш_пароль';
   CREATE DATABASE freelancedesk OWNER freelancedesk;
   ```
2. В `%APPDATA%\FreelanceDesk\config.ini` укажите `backend = postgresql` и заполните секцию `[database]` (образец — `config/config.example.ini`).

Схема базы создаётся и обновляется автоматически при запуске. Вручную миграции применяются командой `python -m freelancedesk.migrate` (с `$env:PYTHONPATH = "src"`).

## Тесты

```powershell
pytest
```

Тесты хранилища запускаются на SQLite и на PostgreSQL. Для PostgreSQL нужна база `freelancedesk_test` и файл `config/config.ini` с параметрами подключения; без них эти варианты пропускаются. Тесты интерфейса работают без показа окон.

## Стек

Python 3.11+, PyQt6, SQLite / PostgreSQL (psycopg 3), pytest.
